# Telemetry Packet Reference

This document lists **every field included in the telemetry packet**, in the **exact order and type** as transmitted.

---

## Header

| Field     | Type    | Description                          |
| --------- | ------- | ------------------------------------ |
| magic     | char[8] | Magic string used to validate packet |
| timeStamp | float   | Packet timestamp                     |

---

## Vehicle Identification

| Field         | Type      | Description           |
| ------------- | --------- | --------------------- |
| vehicleName   | char[256] | Vehicle name          |
| vehicleModel  | char[256] | Vehicle model         |
| vehicleConfig | char[256] | Vehicle configuration |

---

## Engine / Gearbox

| Field           | Type  | Description           |
| --------------- | ----- | --------------------- |
| idle_rpm        | float | Engine idle RPM       |
| max_rpm         | float | Engine max RPM        |
| gear            | int   | Current gear          |
| max_gears       | int   | Maximum gears         |
| gearboxGrinding | int   | Gearbox grinding flag |
